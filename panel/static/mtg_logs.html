Архив пуст: нужно включить debug-логи в mtg

Журнал mtg по умолчанию пишет только ошибки. Чтобы видеть IP всех подключений, добавь debug = true в /etc/mtg/config.toml и перезапусти сервис.

Вариант 1 — кнопкой: панель сама добавит строку и перезапустит mtg.

Вариант 2 — вручную в терминале:

echo 'debug = true' >> /etc/mtg/config.toml && systemctl restart mtg
